## ✨ درباره برنامه

**مدیریت بارگیری و دستمزد** برای استفاده روزانه در انبار طراحی شده است؛ جایی که سرعت، خوانایی و سادگی از هر چیز مهم‌تر است.

کارگر فقط PIN چهاررقمی خود را وارد می‌کند و مدیر هم از همان صفحه وارد می‌شود. خبری از ایمیل، ثبت‌نام یا فرم‌های پیچیده نیست.

## 🎨 رابط کاربری نسخه جدید

نسخه فعلی با تمرکز روی استفاده واقعی با موبایل بازطراحی شده است:

- ☀️ **حالت روز با کنتراست بالا** برای استفاده در محیط روشن و زیر نور آفتاب
- 🌙 **حالت شب** با امکان تغییر دستی تم
- 📱 طراحی **Mobile First** با دکمه‌ها و فیلدهای بزرگ
- 🧩 آیکن‌های SVG یکدست و حرفه‌ای
- 🧾 کارت‌های واضح برای فاکتور و مراحل بارگیری
- 💰 نمایش درشت جمع کل، تسویه‌شده و مانده
- 👷 ظاهر ساده برای کارگر و ابزارهای بیشتر برای مدیر

## 🚀 امکانات اصلی

| قابلیت | توضیح |
|---|---|
| 🔐 **ورود فقط با PIN** | بدون نام کاربری، ایمیل یا ثبت‌نام |
| 🧾 **ثبت فاکتور** | شماره فاکتور و نام صاحب فاکتور |
| 🧱 **بارگیری چندمرحله‌ای** | هر فاکتور می‌تواند چند مرحله بارگیری داشته باشد |
| 👷 **چند کارگر در یک مرحله** | ثبت مبلغ جداگانه برای هر کارگر |
| 💰 **مدیریت دستمزد** | محاسبه جمع کل و مانده |
| ✅ **تسویه** | ثبت وضعیت تسویه‌شده و تسویه‌نشده |
| 🗂️ **بایگانی** | بستن برگه جاری و شروع برگه بعدی |
| 📊 **گزارش** | مشاهده آخرین ثبت‌ها و مبالغ |
| 📁 **CSV / Excel** | خروجی سریع برای حسابداری |
| 🖨️ **چاپ / PDF** | چاپ یا ذخیره گزارش به PDF |
| 🌓 **تم روز و شب** | انتخاب خودکار یا دستی |

## 👨‍💼 مدیر

مدیر می‌تواند تمام ثبت‌ها را ببیند، کارگر جدید بسازد، وضعیت تسویه را مدیریت کند و گزارش بگیرد.

## 👷 کارگر

کارگر فقط با PIN شخصی وارد می‌شود و محیط ساده‌تری برای ثبت بارگیری‌های روزانه در اختیار دارد.

## 🔄 روند کار

**PIN** → **فاکتور** → **انتخاب کارگر** → **مبلغ** → **ثبت مرحله** → **تسویه / گزارش**

## 🛡️ کنترل ثبت تکراری

اگر شماره فاکتور قبلاً وجود داشته باشد، مرحله جدید به همان فاکتور متصل می‌شود. همچنین ثبت‌های بسیار نزدیک با مبلغ یکسان کنترل می‌شوند تا دستمزد ناخواسته دوباره ثبت نشود.
