## ✨ معرفی

**مدیریت بارگیری و دستمزد** یک وب‌اپ فارسی و موبایل‌محور است که برای ساده‌کردن ثبت بارگیری‌ها، محاسبه دستمزد کارگرها، کنترل فاکتورهای چندمرحله‌ای و تسویه طراحی شده است.

هدف برنامه این است که کارگر و مدیر بدون فرم‌های پیچیده، آموزش طولانی یا نرم‌افزارهای سنگین بتوانند کار روزانه را سریع و دقیق ثبت کنند.

## 🚀 امکانات اصلی

| قابلیت | توضیح |
|---|---|
| 🔐 **ورود سریع با PIN** | ورود ساده بدون ایمیل و نام کاربری |
| 🧾 **ثبت فاکتور** | ثبت شماره فاکتور و نام مشتری |
| 🧱 **بارگیری چندمرحله‌ای** | یک فاکتور می‌تواند در چند مرحله بارگیری شود |
| 👷 **چند کارگر در یک بارگیری** | ثبت سهم و دستمزد جداگانه برای هر کارگر |
| 💰 **مدیریت دستمزد** | ثبت مبلغ هر کارگر و محاسبه جمع کل |
| ✅ **تسویه** | مشاهده وضعیت تسویه‌شده و تسویه‌نشده |
| 📊 **گزارش‌ها** | مشاهده آخرین ثبت‌ها و جمع مبالغ |
| 📁 **خروجی CSV / Excel** | دریافت گزارش برای استفاده در حسابداری |
| 🖨️ **چاپ و PDF** | آماده برای چاپ یا ذخیره به‌صورت PDF |
| 🗂️ **بایگانی** | بستن و بایگانی برگه‌های کاری |
| 📱 **مناسب موبایل** | رابط کاربری ساده برای استفاده روزانه در انبار و محل بارگیری |

## 👨‍💼 پنل مدیر

مدیر می‌تواند تمام بارگیری‌ها را مشاهده کند، کارگر جدید بسازد، وضعیت تسویه‌ها را کنترل کند، گزارش بگیرد و اطلاعات ثبت‌شده را مدیریت کند.

## 👷 پنل کارگر

کارگر فقط با PIN شخصی وارد می‌شود و می‌تواند بارگیری‌های مربوط به کار روزانه را ثبت و سوابق خود را مشاهده کند.

## 🔄 روند کار

**ورود با PIN** → **ثبت فاکتور** → **انتخاب کارگرها** → **ثبت دستمزد** → **ثبت مرحله بارگیری** → **تسویه و گزارش**

## 🛡️ کنترل ثبت تکراری

برای جلوگیری از دوباره‌کاری، برنامه شماره فاکتور و ثبت‌های نزدیک به هم را بررسی می‌کند. هر فاکتور می‌تواند چند مرحله داشته باشد، اما ثبت‌های تکراری ناخواسته کنترل می‌شوند.

## 🧩 فناوری‌های استفاده‌شده

- ⚡ **Supabase Edge Functions** برای API
- 🗄️ **PostgreSQL** برای دیتابیس مرکزی
- 🌐 **HTML / JavaScript** برای رابط کاربری
- 📱 طراحی **Mobile First** و کاملاً **RTL**
- 🔑 احراز هویت اختصاصی مبتنی بر PIN
