## ✨ درباره برنامه

**مدیریت بارگیری و دستمزد** برای استفاده روزانه مدیر و کارگرهای انبار ساخته شده است؛ سریع، ساده و بدون فرم‌های اضافی.

ورود فقط با **PIN چهاررقمی** انجام می‌شود. کارگر محیط ساده خودش را می‌بیند و مدیر ابزارهای مدیریتی، تسویه و گزارش را در اختیار دارد.

## 🎨 رابط کاربری

رابط فعلی با یک Design System یکپارچه طراحی شده است: رنگ‌های محدود و هماهنگ، کنتراست بالا برای محیط روشن، حالت شب، کارت‌های مینیمال، دکمه‌های هم‌وزن و آیکن‌های SVG یکدست.

- ☀️ حالت روز مناسب محیط روشن و استفاده در انبار
- 🌙 حالت شب و تغییر تم
- 📱 طراحی Mobile First
- 🧭 ناوبری ساده خانه، بارگیری، سوابق و تنظیمات
- 💰 نمایش واضح جمع کل، تسویه‌شده و مانده
- 🧾 فرم بارگیری کوتاه و کاربردی
- 🔎 جست‌وجو و فیلتر سوابق

## 🗄️ دیتابیس

دیتابیس عملیاتی اصلی برنامه **Supabase / PostgreSQL** است.

یک کانکتور اختیاری **MySQL** نیز داخل پروژه وجود دارد. این کانکتور می‌تواند ساختار لازم را در MySQL ایجاد کند، اتصال را تست کند و اطلاعات اصلی برنامه را به MySQL همگام کند. مشخصات اتصال MySQL از Secretهای امن سرور خوانده می‌شوند و در مرورگر یا ریپوی عمومی ذخیره نمی‌شوند.

> اتصال MySQL تا زمانی که مشخصات سرور MySQL روی محیط سرور تنظیم نشده باشد، در وضعیت «آماده پیکربندی» باقی می‌ماند.

## 👨‍💼 مدیر

مدیر می‌تواند ثبت‌ها را مشاهده کند، کارگر جدید بسازد، تسویه انجام دهد، گزارش بگیرد و وضعیت دیتابیس را بررسی کند.

## 👷 کارگر

کارگر با PIN شخصی وارد می‌شود و محیط ساده‌ای برای ثبت بارگیری‌های روزانه در اختیار دارد.

## 🔄 روند کار

**PIN** → **فاکتور** → **کارگرها** → **مبلغ** → **ثبت مرحله** → **تسویه / گزارش**

## 🛡️ کنترل ثبت تکراری

اگر شماره فاکتور قبلاً وجود داشته باشد، مرحله جدید به همان فاکتور متصل می‌شود. ثبت‌های بسیار نزدیک با مبلغ مشابه نیز کنترل می‌شوند تا دستمزد ناخواسته دوباره ثبت نشود.
