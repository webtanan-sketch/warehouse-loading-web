# دستور کامل ارتقای رابط کاربری

ظاهر وب‌اپ «مدیریت بارگیری و دستمزد» باید حرفه‌ای، تجاری، سریع و کاملاً موبایل‌فرندلی باشد.

## اصول اصلی
- RTL کامل و فارسی
- Mobile-first
- خوانایی بالا در نور زیاد و آفتاب
- تم روز و شب
- دکمه‌ها و فیلدهای حداقل 48px
- آیکن‌های SVG یکدست
- متن‌های کوتاه و انسانی
- تفاوت واضح دسترسی مدیر و کارگر

## رنگ‌های روز

## بخش‌ها
- ورود فقط با PIN چهاررقمی
- داشبورد جمع کل / تسویه‌شده / مانده
- ثبت بارگیری چندکارگره
- بایگانی برگه
- مدیریت کارگرها برای مدیر
- آخرین ثبت‌ها و تسویه
- خروجی CSV و چاپ/PDF
- تغییر PIN

## خروجی
خروجی باید حس یک نرم‌افزار واقعی تجاری داشته باشد، نه نمونه آزمایشی.
