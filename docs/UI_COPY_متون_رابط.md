# متن‌های آماده رابط کاربری

## ورود
- ورود به برنامه
- فقط PIN چهاررقمی را وارد کنید.

## داشبورد
- جمع کل
- تسویه‌شده
- مانده

## ثبت بارگیری
- شماره فاکتور
- نام صاحب فاکتور
- کارگرها و مبلغ هر نفر
- توضیحات
- افزودن کارگر
- ثبت مرحله بارگیری
- بایگانی برگه جاری

## مدیریت کارگرها
- نام کارگر
- PIN چهاررقمی
- ساخت حساب کارگر

## وضعیت‌ها
- تسویه شده
- تسویه نشده
- ثبت با موفقیت انجام شد
- برگه بایگانی شد
- PIN با موفقیت تغییر کرد
- هنوز ثبتی وجود ندارد
