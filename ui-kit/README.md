# UI Kit حرفه‌ای مدیریت بارگیری

این پوشه شامل بسته کامل طراحی رابط کاربری نسخه جدید است.

فایل `Warehouse_UI_Kit_Pro_v1.zip` شامل موارد زیر است:

- نمونه HTML موبایل‌فرندلی
- CSS حرفه‌ای با تم روز و شب
- JavaScript اولیه رابط
- PWA Manifest
- آیکن‌های SVG یکدست
- متن کامل برای برنامه‌نویس
- متن‌های آماده رابط کاربری

نسخه عملیاتی برنامه نیز در `supabase/functions/warehouse-client-js/index.ts` قرار دارد و رابط آنلاین فعلی از همان فایل استفاده می‌کند.
